## Publicación en GitHub Pages

1. Extrae el ZIP.
2. Sube **el contenido** de esta carpeta a la raíz de un repositorio público de GitHub (debe existir `index.html` en la raíz).
3. En GitHub, entra a **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.
4. Abre `https://TU_USUARIO.github.io/NOMBRE_REPOSITORIO/` y comprueba el sitio en móvil y escritorio.
5. Revisa imágenes, menú, enlaces internos, temporizador y simulación con TEUS.
